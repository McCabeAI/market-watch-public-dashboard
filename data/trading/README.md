# Durable trading memory

Git-backed ledger, decision journal, and compact identity learning memory for the locked 14 traders and 4 PMs.

Trusted code owns every canonical fact. Models may supply structured decisions, postmortems, and lesson updates only.

See `docs/TRADING_LEDGER_MEMORY_V1.md`. Open positions carry a deterministic profit-harvest block. Entry lifecycle and full-size harvest reviews are decision inputs. Thresholds do not create orders.
